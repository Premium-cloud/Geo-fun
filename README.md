# Drapeaux du monde

Jeu de cartes des pays du monde : drapeau, continent, capitale. Verso unifié « DRAPEAU DU MONDE ».

## Lancer en local

```bash
npm install
npm run dev
```

L’app tourne sur [http://127.0.0.1:43125](http://127.0.0.1:43125).

## Utilisation

- Cliquez une carte pour la retourner
- Filtrez par continent ou recherchez un pays / une capitale
- `Ctrl/Cmd + P` pour imprimer (recto puis verso miroir, 9 cartes par feuille A4)

## Stack

Vite + React + TypeScript. Drapeaux via [flagcdn.com](https://flagcdn.com).
